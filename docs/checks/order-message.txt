交付说明（v1，2026-11-21）：仓库 https://github.com/liaoyuqing/clawhunt-2053-academy-course-list （公开、匿名可读，页面代码、23 张截图、2 段录屏、5 份检查日志都在里面）。以下是三条验收的复现方式。

【跑起来】npm install → npm run build && npm run serve → 打开 http://127.0.0.1:5201/academy/courses 。无需后端、无需密钥，接口全部是本地 mock（36 条虚构课程）。

【AC1 · 5 种状态按钮组合各有截图，且与 README 矩阵一致】
① 打开 /academy/courses?status=draft ，把 draft 依次换成 pending_review / published / offline / archived，共 5 次，每次截一张图（状态标签与操作列同屏）。
② 对照 README 的「按钮矩阵」区块：草稿=编辑/复制/提交审核/删除；待审核=复制/审批；已发布=复制/下架/归档；已下架=编辑/复制/重新上架/归档；已归档=复制/删除。
我方已出图：docs/screens/state-draft.png、state-pending_review.png、state-published.png、state-offline.png、state-archived.png（各附 -actions-closeup.png 操作列特写），另有 matrix-overview-all-states.png 为 36 条课程 5 状态同屏。
矩阵不是手写的：README 区块由 scripts/export-action-matrix.mjs 调 src/domain/actions.ts 的 actionPresence() 生成，按钮渲染走同一函数 actionMatrix()；tests/readme-matrix.test.ts 会逐字比对 README 区块与现算结果，tests/page-ac1-buttons.test.tsx 逐行断言 DOM 的 data-actions 等于矩阵返回值。一键重出：npm run screens。

【AC2 · 刷新后筛选条件从 URL 恢复（录屏）】
① 打开 /academy/courses ② 勾「草稿」再勾「已发布」 ③ 关键词框输入「招商」→ 地址栏变为 ?status=draft,published&q=招商 ④ 按 F5 → 筛选栏仍是这两个勾选 + 关键词，列表结果不变。
录屏：docs/recording/ac2-url-restore-refresh.webm（17 秒，Playwright 直录无剪辑，F5 是真实按键）。静态备份 ac2-before-url-01-clean / ac2-before-url-02-filters-set / ac2-after-reload-01-restored .png。实测数据在 docs/screens/evidence.json：刷新前后 URL 完全相同，刷新后关键词「招商」、勾选「草稿/已发布」、结果 2 行。
实现要点：筛选条件唯一真源是 URL，页面不存第二份 state，任何变更都 navigate 写回；默认值不写进 URL（干净状态就是 /academy/courses）；非法值白名单收敛，手改坏参数不白屏（ac2-malformed-url-still-works.png）。重录：npm run video。

【AC3 · 无 publish 权限时不显示审批按钮（截图）】
① 打开 /academy/courses?status=pending_review ② 右上角账号下拉切到「演示 · 课程运营」（无 publish 权限）→ 待审核行只剩「复制」，审批按钮消失。
截图：docs/screens/ac3-no-publish-permission.png（DOM 内审批按钮计数 0）；对照组 ac3-control-with-publish-permission.png（切「演示 · 平台管理员」，同一批行出现「审批」，计数 7）；边界 ac3-boundary-self-submitted.png（「演示 · 审核专员」有 publish 权限但本人是 CRS-1012/1015 的提交人，这两行仍无审批）。
关键点：按钮不是置灰而是不渲染 —— ActionButtons 只遍历 actionMatrix() 的返回值，无 disabled 分支；权限来自 mock IAM 的 permissions 数组，切账号即变。动态证据：docs/recording/ac3-permission-switch.webm（0→7→0）。
